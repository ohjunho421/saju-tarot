# 랜딩·마이페이지

## 설명

- 랜딩(HomePage): 서비스 소개, "이렇게 풀어드려요" 결과 예시, 기능 3개, 이용 방법 4단계. 비로그인으로 볼 수 있다.
- 마이페이지(MyPage): 로그인 사용자의 생년월일시, MBTI 설정, 사주 결과(`SajuResult`), 활용 팁.

## 문구 원칙

- 해요체, 결론 먼저, 용어는 쉬운 말로(스프레드 → 카드 배치, 오행 → 나무·불·흙·쇠·물 다섯 기운).
- AI 상투어("융합", "운명을 깊이 있게 들여다봅니다")·과장·교훈조 마무리 금지.
- 사실과 다른 숫자를 쓰지 않는다(예: 스프레드 개수).
- 랜딩 결과 예시는 정적 예시이며, 결과 화면 쉽게 보기(`EasyReadingView`)와 같은 모양을 유지한다.

## 주의사항

- 마이페이지 사주 결과는 리딩 흐름의 사주 단계와 같은 `SajuResult`를 쓴다. 한쪽을 바꾸면 둘 다 바뀐다.
- `birthInfo.hour`는 선택 입력이다(모름이면 없음). 표시할 때 반드시 없는 경우를 처리한다.
