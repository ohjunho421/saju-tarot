# 랜딩·마이페이지

## 설명

- 랜딩(HomePage): 비로그인으로 볼 수 있다. 위에서부터 다섯 구역.
  1. 첫 화면(HeroTable): 밤 남색 탁자 위에 실제 고양이 카드가 흩어져 놓이고 가운데 제목·설명·금색 시작 버튼. 카드는 먼·중간·가까운 세 층이라 스크롤하면 층마다 다른 속도로 올라간다. 휴대폰 6장, 태블릿 이상 8장, 넓은 화면 10장.
  2. 결과 예시(SampleReading): 큰 여사제 카드가 기울어진 채 들어와 똑바로 서고, 결과 쉽게 보기와 같은 모양(질문·신호·한 줄 결론·3단계)이 차례로 떠오른다.
  3. 세 가지 읽기(ThreeReads): 타로(넓은 칸, 카드 부채)·별자리·사주를 크기와 면 색이 다른 칸으로. 사주 칸은 다섯 기운 칩(많음·적음을 글자로도 표시).
  4. 이용 방법(HowItWorks): 4단계. 휴대폰은 세로 선, 넓은 화면은 가로 선.
  5. 마무리(ClosingCall): 질문 한 줄과 시작 버튼, 로그인 안내 문구.
- 디자인 기준은 루트 `DESIGN.md`(색·글꼴·그림자·움직임 규칙), 제품 맥락은 `PRODUCT.md`.
- 마이페이지(MyPage): 로그인 사용자의 생년월일시, MBTI 설정, 사주 결과(`SajuResult`), 활용 팁.

## 문구 원칙

- 해요체, 결론 먼저, 용어는 쉬운 말로(스프레드 → 카드 배치, 오행 → 나무·불·흙·쇠·물 다섯 기운).
- AI 상투어("융합", "운명을 깊이 있게 들여다봅니다")·과장·교훈조 마무리 금지.
- 사실과 다른 숫자를 쓰지 않는다(예: 스프레드 개수).
- 랜딩 결과 예시는 정적 예시이며, 결과 화면 쉽게 보기(`EasyReadingView`)와 같은 모양을 유지한다.
- 이용 후기·이용자 수·평점은 쓰지 않는다(실제 근거가 없다). 가격은 정해지지 않았으므로 랜딩에 넣지 않는다.

## 주의사항

- 마이페이지 사주 결과는 리딩 흐름의 사주 단계와 같은 `SajuResult`를 쓴다. 한쪽을 바꾸면 둘 다 바뀐다.
- `birthInfo.hour`는 선택 입력이다(모름이면 없음). 표시할 때 반드시 없는 경우를 처리한다.
- 랜딩 카드 그림은 `client/public/landing/cards/`의 웹용 webp(320px, 큰 카드 520px)를 쓴다. 원본 `server/src/public/tarot-images`의 큰 png를 랜딩에 직접 쓰지 않는다. 새 카드를 넣으면 같은 크기로 변환하고 옆에 출처 파일(`*.webp.json`)을 둔다.
- 제목 글꼴 Gowun Batang은 `@fontsource/gowun-batang`으로 HomePage에서만 불러온다(외부 글꼴 서버 호출 없음).
- 움직임(카드 놓기, 스크롤 층, 결과 단계 떠오르기)은 `useReducedMotion`이 켜지면 처음부터 제자리에 멈춘 상태로 그린다. 움직임을 추가하면 이 정지 상태도 함께 만든다.
- 한글 제목·안내문에는 `break-keep`(+제목은 `text-balance`)을 붙인다. 빼면 휴대폰에서 "볼까 / 요?"처럼 글자 하나가 다음 줄로 떨어진다.
- 헤더·푸터(`App.tsx`)는 아직 기존 보라색 버튼·그라데이션 글자 그대로다. 랜딩 본문만 금색 강조로 바뀌었다.
